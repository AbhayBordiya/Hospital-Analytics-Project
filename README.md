# 🏥 Hospital Operations & Patient Analytics

## About the Project
This is a complete data analytics project on hospital data.
I used three tools — Excel, MySQL and Power BI — to clean data,
write SQL queries, and build an interactive dashboard.

## Tools Used
| Tool | What I Did |
|------|-----------|
| Excel | Data cleaning, fixing missing values, Pivot Tables |
| MySQL | Created database, wrote 15 SQL queries |
| Power BI | Built 3 page interactive dashboard |

## Dataset
- 5 Tables: Patients, Appointments, Doctors, Billing, Treatments
- Total Records: ~24,000 rows
- Data Period: 2022 - 2023

## Key Insights
- Diabetes Type 2 and Migraine are top conditions — 154 patients each
- Insurance generates highest revenue — 2.27 Crore (55% of total)
- 60% appointments successfully completed
- 10% No-show rate — hospital needs better reminder system
- Cardiology has most treatments — 790
- 60+ age group has most patients — 799
- October had highest revenue in both years
